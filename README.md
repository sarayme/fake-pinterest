# Fake Pinterest 📌

Projeto desenvolvido durante o **minicurso de Introdução a Python e Flask da Hashtag Treinamentos**, como parte dos meus estudos em desenvolvimento web com Python.

O projeto é inspirado na proposta e interface do Pinterest e foi desenvolvido para praticar conceitos de desenvolvimento web com Python e Flask, incluindo criação de rotas, templates, formulários, autenticação de usuários e integração com banco de dados.

## 🚀 Tecnologias

* Python
* Flask
* Flask-WTF
* WTForms
* Flask-Login
* SQLAlchemy
* SQLite
* HTML
* CSS

## 📌 Funcionalidades

* Cadastro de usuários
* Login
* Validação de formulários
* Criação e exibição de posts
* Feed de posts
* Perfil de usuário
* Upload e exibição de imagens
* Persistência de dados em banco de dados

## 🛠️ Como executar

### 1. Clone o repositório

```bash
git clone git@github.com:sarayme/fake-pinterest.git
cd fake-pinterest
```

### 2. Crie o ambiente virtual

```bash
python3 -m venv .venv
```

### 3. Ative o ambiente virtual

No Linux/WSL:

```bash
source .venv/bin/activate
```

### 4. Instale as dependências

```bash
pip install -r requirements.txt
```

### 5. Execute o projeto

```bash
python main.py
```

Depois, acesse:

```text
http://127.0.0.1:5000
```
